# El Escritorio del Director

Aplicación Android para dirección y administración escolar, parte del ecosistema formado por El Cuaderno del Maestro, El Cuaderno del Estudiante y El Escritorio del Director.

Estado actual: versión inicial Android con navegación base, dashboard institucional demo y flujo de compilación APK en GitHub Actions.

Próximas áreas: docentes, estudiantes, grupos, materias, horarios, cobertura académica, avisos, calendario institucional, ciclos escolares, estadísticas y configuración.
